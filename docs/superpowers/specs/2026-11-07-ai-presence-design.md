# 子项目 B：AI 的存在感 —— 设计规格

日期：2026-11-07　分支：`ai-presence`（基于 `camera-control`）　动态草图：项目根目录 `ai-light.html`（不进 git）

## 1. 问题与目标

用户反馈：AI 界面太技术化，动画不够好，别人看不出那是 AI。

具体表现：
- 现在 AI 的表达是一组仪表：条件芯片（清晰✓ 睁眼○…）、阶段文字、评分条、一道扫描线。
- 子项目 A 之后 AI 做的事情变多了：换镜头、调曝光、追主体、等时机、连拍选片。这些在画面上几乎看不见。

目标：
1. 普通人一眼看出「AI 在工作」，并且看得出它在看哪里。
2. AI 做的每个动作都在画面上有对应的动画。
3. AI 用人话说明自己在做什么。技术细节全部收进详情面板。

用户的选择（2026-11-07）：
- AI 的形态是「有生命的光」，同时配合「看得见的动作」和「说人话的搭档」。
- 光的方案选了 A + C（极光边缘 + 呼吸光晕）。
- 配色选了青色主调。全套 AI 仍然只用品牌青（#3DF5C8），只在流动中带少量蓝绿（#2FD6C9、#7AA8FF、#8EF7DC）。

## 2. 视觉语言

### 2.1 极光边缘 `AuroraEdge`

AI 开启时，裁切框（也就是 AI 的构图框）的边缘有一圈流动的青色极光：一条 3 pt 的锐利描边，外面套一层模糊的光晕。

| 状态 | 表现 |
|---|---|
| 观察（scouting） | 慢速流转（每圈约 6.5 秒），亮度 0.55 |
| 认出主体 | 最亮的一段转到主体所在的一侧（角向渐变的中心向主体偏移 80%） |
| 等时机（planning / composing） | 流转速度和描边宽度随时机分上升；时机分 ≥ 0.9 时开始呼吸，周期 0.9 秒 |
| 拍下（capturing） | 0.3 秒内向中心收拢 4%，同时变亮，之后淡出 |
| 冷却 / 暂停 | 降到 0.35 亮度，极慢流转 |
| 离线 | 与正常相同，字幕说明离线 |
| 减少动态效果 | 不流转、不呼吸，保持静态渐变；状态变化用 0.2 秒的淡入淡出表示 |

### 2.2 呼吸光晕 `AttentionHalo`

取景画面上叠一团淡青色的径向光晕，并配合四周轻微压暗，表示 AI 的视线落在哪里：
- 有主体时光晕落在主体中心。
- 没有主体时（观察中）在画面中缓慢游移。

具体参数：
- 半径为短边的 30%–40%，随时机分变大。
- 强度上限为不透明度 0.32，以免改变取景观感。
- 混合模式用 screen。
- 拍下时光晕收缩为 20% 并淡出。

### 2.3 看得见的动作

| AI 的动作 | 画面上的表现 |
|---|---|
| 认出主体 | 主体外的白色细角框以弹簧动画「析出」（从放大 1.15 倍、透明，落到 1 倍） |
| 换镜头 | 真实的变焦 ramp 本身就是推拉，再配一句字幕 |
| 拍下 | 光晕与极光收拢，取景画面闪白（0.45 秒，峰值 0.85），快门按钮按下 |
| 选片 | 取景器底部弹出 6 张缩略图（依次间隔 0.07 秒）；被选中的那张抬起、描青边、标「AI 选择」；1.6 秒后整组淡出，选中的那张出现在左下角的缩略图按钮上 |

### 2.4 字幕 `AICaption`

字幕显示在取景器底部，替代 `AIAnnotation` 和状态行里的条件芯片：
- 一次只显示一句，最多 16 个字。
- 2.5 秒后淡出；同一句话 8 秒内不重复。
- 只用人话，不出现阈值、分数和英文。

字幕内容由纯函数 `CaptionDirector`（CameraCore）根据状态变化生成。按优先级从高到低：

| 事件 | 字幕 |
|---|---|
| 选片完成 | 人像、合影：「挑了眼睛睁开的一张」；其他题材：「挑了最清楚的一张」 |
| 自动拍下 | 「就是现在」 |
| 换镜头 | 「换到 2×，背景虚一点」。后半句按意图选择：浅景深为「背景虚一点」，13 mm 为「装下整个空间」，长焦为「拉近一点」，其余情况不加 |
| 导演意图到达 | 意图理由的第一个分句（按「，。；：,」切分，截到 16 字） |
| 题材确定（使用默认意图） | 「像是{题材}」 |
| 弱光 | 「光线有点暗，拿稳一点」 |
| 离线 | 「没有网络，先按经验拍」 |
| 等某个信号持续 1.5 秒 | eyesOpen「等眼睛睁开」；faceToward「等脸转过来」；deviceStill「拿稳一点」；horizonLevel「把手机放平」；subjectSharp「等对上焦」；subjectPlaced「等主体到位」；highlightsSafe「压一压高光」 |
| 侦察开始 | 「在看这是什么场景」 |
| 冷却 | 「拍好了，换个场景继续」 |

### 2.5 状态行

固定控制区里的状态行改成一句简短的人话：「● 人像 · 2× 浅景深」。冷却时显示「● 拍好了」，离线时显示「● 离线」。

- 删除条件芯片。
- 整行点开仍然是详情面板，标识 `camera.agent` 与无障碍取值「第 N 轮」保持不变。

### 2.6 保留与删除

| 处理 | 对象 |
|---|---|
| 删除 | 扫描线（极光取代它）；AI 开启时的青色角标呼吸（极光取代它）；`AIAnnotation`；主界面上的 `TriggerChips` |
| 保留 | AI 关闭时的白色角标；读数的颜色语义；快门环（亮度跟随时机分）；AI 按钮；详情面板（技术细节全部在这里） |
| 调整 | 裁切框外的压暗从 0.55 降到 0.45；裁切框不再单独画青线，由极光承担 |

## 3. 结构

- **CameraCore**：`CaptionDirector`、`PresenceModel`，都是纯函数并配有测试。
  - `CaptionDirector`：输入 `CaptionSnapshot`，输出当前字幕。
  - `PresenceModel`：输入阶段、时机分、主体框，输出极光与光晕的参数：亮度、速度、宽度、视线点、呼吸。
- **App 的 `Design/Presence/`**：
  - `AuroraEdge`、`AttentionHalo`、`CaptureFlash`、`BurstFilmstrip`、`AICaption`；
  - 由 `TimelineView(.animation)` 驱动，30 fps。
- **AgentController**：维护 `CaptionDirector`，对外提供 `caption`；记录 `lastCaptureAutomatic`。
- **CameraModel**：选片完成时发布 `burstPreview`（6 张缩略图、选中序号、id）。

## 4. 性能与无障碍

- 所有光效只在 AI 开启时渲染。
- 极光用一次描边加一层模糊，光晕用一个径向渐变，不做逐像素计算。
- 减少动态效果见 §2.1；光晕在这种模式下静止在主体位置。
- 字幕通过 `AccessibilityNotification.Announcement` 播报（同一句话 8 秒内不重复）。
- 光效层不参与无障碍。

## 5. 测试

- **CameraCore**：
  - `CaptionDirector`：优先级、16 字截断、8 秒内不重复、等待信号需要持续 1.5 秒、换镜头的后半句。
  - `PresenceModel`：各状态的参数、视线点偏移、拍下时收拢。
- **真机截图**：`DesignScreenshotTests` 增加 `picking` 演示场景（选片动画），各场景都截图检查。
- **交互测试**：现有交互测试继续通过。
