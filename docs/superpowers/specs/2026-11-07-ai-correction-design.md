# 子项目 C3：AI 修正 —— 设计规格

日期：2026-11-07　分支：`ai-correction`（基于 main 171db85）

## 目标

用户说「先修正，再风格」：不加任何风格，照片也要比系统相机好看。C3 在本机按每一帧的测量，自动算出一层修正，放在用户选的滤镜之前：
- 管线：原片 → AI 修正 → 用户滤镜。
- 滤镜强度不影响修正层。

## 1. 测量补充（感知层）

`SceneMeasurement` 新增可选字段 `chroma: ChromaStats`，从 YCbCr 帧的 CbCr 平面按步长采样得到：
- `cb`、`cr`：中间调像素（亮度 0.2–0.8）的平均色度，范围 −0.5…0.5，用来判断偏色。
- `saturation`：平均色度幅值，用来判断画面是否平淡。
- `topLuma`、`topCb`：画面上方 30% 的平均亮度和平均 Cb，用来判断是否有天空。

## 2. 新的局部操作（`LookOp`）

| op | 参数与范围 | 实现（内置着色器） |
|---|---|---|
| subjectLight | x、y（0…1，左上原点）；radius（0.05…1，相对短边）；amount（−1…1 EV） | 以 (x, y) 为中心的柔和径向蒙版：内圈半径 0.6r，外圈 1.4r，按宽高比修正；在近似线性空间中乘以 2^(amount·mask) |
| skyRecover | amount（0…1）；horizon（0…1，天空下沿） | 天空程度 = 亮度 smoothstep(0.35, 0.8) × 偏蓝程度 clamp((b − r)·3 + 0.4) × 位于 horizon 以上；然后压暗 0.8·amount EV，饱和度提高 0.3·amount |

这两个操作也可以出现在任何配方里，C4 的 AI 也能使用。

## 3. `CorrectionPlanner`（CameraCore，纯函数）

**输入**：测量、题材、是否有人脸、主体框。

**输出**：`CorrectionParams`，全部使用全画幅坐标：

| 参数 | 规则 |
|---|---|
| 白平衡 | 暖度 = cr − cb。\|暖度\| > 0.05 时校正：temperature = clamp(−暖度 × 1.2, −0.25, 0.25) × 0.5，tint = clamp(−(cb + cr), −0.2, 0.2) × 0.5。<br>以下情况不纠正偏色，保留氛围：夜景题材；风光题材且画面偏暖（日落） |
| 高光 | highlights = −clamp((clipHigh − 0.002) × 25, 0, 0.5) |
| 阴影 | shadows = clamp((clipLow − 0.01) × 15, 0, 0.3) + max(0, 0.3 − mean) × 0.8，整体上限 0.35；夜景上限 0.15 |
| 主体补光 | 有主体，且主体亮度 < 整体亮度 × 0.75（逆光）时：amount = clamp(log2(整体 / 主体) × 0.6, 0, 0.7)，人像题材 × 1.2。<br>中心为主体框中心；半径：人脸取 max(w, h) × 1.5，其余取 max(w, h) × 0.9 |
| 天空恢复 | topLuma > 0.6 且 topCb > 0.02 时：sky = clamp((topLuma − 0.55) × 2, 0, 0.7)，horizon = 0.45 |
| 肤色 | 有人脸时，HSL 橙色段饱和度 −0.06、明度 +0.05 |
| 平淡画面 | saturation < 0.06 且不是黑白相关场景时，自然饱和度 +0.1 |

`CorrectionParams.ops(for crop: NormalizedRect) -> [LookOp]`：
- 把局部操作的坐标换算到裁切框内（成片用裁切后的坐标，取景用全画幅 `.full`）；
- 主体中心落在框外时，不做主体补光。

**`CorrectionSmoother`**：对数值参数做指数平滑，时间常数 0.6 秒，防止画面闪烁。主体中心的跟随时间常数为 0.15 秒。

**`CorrectionParams.note`**：用一句话描述最显著的修正，比如「逆光，提亮了人脸」「压了压天空」「去掉了偏色」，交给字幕使用（优先级 45）。

## 4. 接入

- **AgentController**：每次测量后计算并平滑修正参数，对外发布 `correction`；`smartCorrection` 开关默认开启，放在详情面板里。AI 关闭时没有修正，因为感知层不运行。
- **LiveRenderer**：在配方之前单独渲染修正层（使用 `.full` 坐标）。
- **成片**：按快门时冻结修正参数和裁切框，渲染时使用 `ops(for: crop)`。
- **字幕**：`CaptionSnapshot` 新增 `correctionNote`，内容变化时出字幕（同样受 8 秒内不重复的限制）。
