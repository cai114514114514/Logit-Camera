# 子项目 C2：配方与预设 —— 设计规格

日期：2026-11-07　分支：`look-presets`（基于 main c9f4070）

## 目标

在 C1 的渲染底座之上：
1. 补齐调色工具，让配方能表达真正好看的风格。
2. 内置 9 个精心调过的预设（JSON 随包分发，社区可以改）。
3. 取景时可以挑滤镜（带实时缩略图）、调强度、逐项微调，并保存为自己的滤镜。
4. 拍完的照片可以换滤镜重新渲染，另存为新照片。

## 1. 新增调色操作（`LookOp`）

| op | 参数与范围 | 实现 |
|---|---|---|
| highlightsShadows | highlights −1…0（恢复高光）、shadows −1…1 | CIHighlightShadowAdjust；半径为短边的 1% |
| hsl | bands：最多 8 条，每条 `{band, hue, saturation, luminance}`，取值各 −1…1；band 为 red、orange、yellow、green、aqua、blue、purple、magenta 之一 | 内置着色器：按色相距离加权，低饱和像素受影响更小；hue ±1 对应 ±30° |
| colorGrade | shadows、midtones、highlights 各 `{hue 0…360, amount 0…1}`，balance −1…1 | 内置着色器：按亮度分三段加权，保持亮度不变地叠加色偏 |
| grain | amount 0…1、size 0…1 | 内置着色器：哈希噪声，颗粒尺寸以画面短边为参照（取景和成片一致）；取景中随时间变化，成片中静止 |
| vignette | amount −1…1（负值压暗）、midpoint 0…1 | 内置着色器，按画面宽高比修正 |
| mono | red、green、blue 各 0…1（权重） | 内置着色器：按权重混合成黑白 |
| bloom | amount 0…1 | CIBloom；半径为短边的 2% |

此外：
- **感知空间**：toneCurve 和 fade 改为在 sRGB 编码空间中计算（先转换、处理完再转回），曲线的手感才和 Lightroom 一致。
- **内置着色器**：复用 C1 的 `CustomShaderKernel`。内置代码可信，不经过沙箱校验。
- **公共辅助函数**：模板里提供 `logit_luma`、`logit_rgb2hsl`、`logit_hsl2rgb`、`logit_hue_rgb`、`logit_hash`，AI 写的自定义着色器（C4）也能使用。
- **参数数组**：`LookParams.v` 扩展到 32 个，自定义着色器仍然只开放前 8 个。

## 2. 预设（`Resources/Knowledge/looks/*.json`）

| 预设 | 定位 |
|---|---|
| 原片 | 不调色 |
| 自然 | 只做修正：恢复高光、提一点阴影、自然饱和度加 0.15、轻微 S 曲线 |
| 通透 | 日系：提亮、低对比、抬黑；阴影偏青、高光微暖；绿色往青色偏、降低饱和；肤色提亮 |
| 胶片暖 | Portra 一类：偏暖、高光柔和地滚降；绿色偏黄并降低饱和；细颗粒、轻微暗角 |
| 电影冷调 | 克制的青橙：阴影偏青、高光偏橙；略微压暗黑位；暗角 |
| 黑白 | 红 0.4、绿 0.45、蓝 0.15 的权重混合；高对比 S 曲线；颗粒 |
| 夜色 | 偏冷、恢复高光；暗部偏蓝；光晕 |
| 浓郁 | 自然饱和度加 0.35；蓝天更深、更饱和 |
| 柔光人像 | 微亮、低对比；肤色降饱和并提亮；高光微暖；轻光晕 |

`Knowledge.looks()` 按文件名排序加载这些预设，「原片」排在最前。每个预设都必须能通过 `validate()`。

## 3. 微调与保存

- **`LookAdjustments`**（CameraCore）：曝光、色温、色调、对比、高光、阴影、饱和、自然饱和、褪色、颗粒、暗角，共 11 项，默认都是 0。
  - `apply(to:)` 把非零项追加成操作：曝光、白平衡、高光阴影追加到修正层末尾，其余追加到风格层末尾。
  - `effective = preset + adjustments`，强度滑杆对应 `strength`。
- **我的滤镜**：保存当前生效的配方，并让你命名。存储位置为 `Application Support/Looks/mine.json`，排在预设之后；长按可以删除。

## 4. 界面

- **入口**：HUD 里新增「滤镜」按钮。打开后，取景器下方的变焦档换成滤镜条（与手动拨盘互斥）。
- **滤镜条**：
  - 横向滚动，每项是一张 52×68 的实时缩略图加名字。缩略图来自最新一帧，按各自的配方渲染，每 0.6 秒刷新一次，只在滤镜条打开时运行。
  - 选中项描白边。选中的不是「原片」时，下方出现强度滑杆（0–100%）和「调整」按钮。
- **调整面板**（sheet）：11 个滑杆，每个都有「重置」；可以「存为我的滤镜」；修改实时作用在取景上。
- **照片详情**：有一条滤镜缩略图（基于这张照片的原片）。选择后预览重新渲染；点「存为新照片」把这个版本加进相册（原来那张保留）。
- **与 AI 的关系**：滤镜由人选择，选滤镜不会停止 AI，AI 也不会改滤镜（AI 改滤镜在 C4）。
